# 上海婦孺醫院紀事（約 1891） / Our Hospital in China — Transcription Dataset

S. D. Doremus 的《Our Hospital in China》約於 1891 年由紐約婦女聯合傳教會刊行，記述上海 Margaret Williamson Hospital 的婦孺病房、早期患者住院和華人護士的訓練。這份短刊保存了晚清女性患者與護理教育在傳教醫院記錄中的面貌。

Published in New York around 1891 by the Woman’s Union Missionary Society, S. D. Doremus’s Our Hospital in China describes women’s and children’s wards, early admissions, and the training of Chinese nurses at Shanghai’s Margaret Williamson Hospital.

## Source and scope

Columbia University Libraries, The Burke Library, OCLC 55769934 / ourhospitalinchi00dore, Source frames 1–6. Original imprint: Woman’s Union Missionary Society, New York, [1891]. All six imaging frames are indexed. The transcription covers the four printed pages. The edition records later marks separately where visible.

## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
## Transcription and review

AI-assisted reading used fixed source scans. Published text preserves printed spellings and historical terminology. Spacing may be normalized. A square (□) indicates an unresolved character. See the notes for editorial omissions and uncertain readings.
